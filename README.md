# CalcBloc Calculators for WordPress

Add free salary, take-home pay and income tax calculators to any WordPress site with a shortcode or a block. The calculators run inside an isolated frame, so they cannot break your theme, and every result uses CalcBloc's sourced 2026 tax tables.

> **Status:** in development. This repository will hold the source code; nothing has been released yet.

## What it will do

- **Shortcode:** `[calcbloc country="uk" calculator="take-home-pay"]`
- **Block:** pick a country and calculator in the block editor.
- **Lightweight and mobile friendly:** one small script and an iframe; no tracking.
- **Credit:** a visible "Powered by CalcBloc" link to the matching calculator page.

The plugin wraps the CalcBloc embed widget (also available as a plain script tag at [calcbloc.com/embed](https://calcbloc.com/embed)).

## Data and licence

Tax data comes from [CalcBloc](https://calcbloc.com/data): every figure is taken from the official government source named next to it, with the date it was last checked. Data licence: CC BY 4.0, credit "Data by CalcBloc (calcbloc.com/data)". Code licence: MIT.
